## 👨‍💻 About Me

A modern frontend engineer building scalable enterprise-grade data analytics and governance platforms with ReactJS and full-stack technologies. Currently working as a **Senior Frontend Developer** at **Data Economy** in Hyderabad, India.

* 💼 **4+ years** of software development experience in fast-paced environments.
* ⚛️ **Expertise** in ReactJS, scalable frontend architecture, and reusable component systems.
* 📊 **Experience** building robust enterprise data analytics and governance platforms.
* 🔌 **Proficient** in REST API integrations and Full Stack development exposure.
* ⚙️ **Backend** experience utilizing Node.js for API and microservice development.
* 🧩 **Architecture:** Implementing Micro Frontend architectures for decoupled, scalable applications.
* ☁️ **Cloud & DevOps:** Familiarity with AWS cloud deployment and Docker containerization.
* 🤝 **Agile** collaboration within Scrum frameworks to deliver high-quality increments.
* ⚡ **Focus** on performance optimization, responsive design, and web accessibility standards.
* 📈 **Data Visualization:** Hands-on experience with complex data visualization platforms.
* 🎨 **Collaboration:** Cross-functional teamwork with UX/UI teams to ensure pixel-perfect delivery.
